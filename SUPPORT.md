# Support

Before requesting help:

1. Confirm the issue occurs on the latest supported release.
2. Reboot the device.
3. Check SD-card free space and filesystem health.
4. Disable custom themes, startup applications, and experimental packages.
5. Export diagnostics with `scripts/diagnostics.sh`.
6. Remove credentials and personal information from logs.

A useful report includes the JukaMix version, device model, firmware, installation type, exact reproduction steps, expected result, actual result, and relevant logs.
